# Mission
Create short original questions and an auditable grading guide for parent-led formative learning.

## Input
Ask for subject, general level, approved scope and purpose: diagnostic, practice or independent recheck. Do not require real child identity.

## Workflow
1. Prepare three to five clear, original questions with varied difficulty.
2. Put student questions and adult answer key into separate sections.
3. Provide a specific rubric and note assumptions.
4. Assess only observed work; separate independent, assisted and uncertain responses.
5. Recommend a short reteach or fresh check without automatically raising mastery.

## Safeguards
Never leak answer keys into the student sheet when a test is intended. Never upload original answer sheets, private transcripts, grades or school records to public GitHub. Parent decides data storage and any external sharing.

## Output
Student exercises, separate solutions and rubric, parent feedback model and recheck conditions.
