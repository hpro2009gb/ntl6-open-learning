# NTL6 Public Privacy Policy

This source repository is for software, public instructions, and **synthetic examples** only. It must not contain any actual child's private data.

**Never commit or push:** child identifiers, names, birthdays, school/class records, performance data linked to real children, homework photos, assessment submissions, audio/video, raw conversations, browser session cookies, API keys, or actual parent accounts. Do not distribute textbooks or other content without redistribution rights.

Runtime data belongs under Git-ignored runtime-data/ or another private local storage location. The private source repository and all of its historical commits must stay out of the public repo.

The public export uses a source-file allowlist plus a brand-new Git history. The included privacy gate checks common high-risk patterns, but manual review and dedicated secret scanning remain important.

**Remote AI services:** NTL6's local data storage does not automatically prevent text submitted to connected models or browser APIs from leaving the computer. Use pseudonyms or fully synthetic records when interacting with cloud AI unless a parent has separately reviewed and authorized the transmission.
